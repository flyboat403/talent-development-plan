# 职业教育人才培养方案编制技能

基于教学标准与职业分析报告，自动生成**符合国家规范的职业院校人才培养方案**（Markdown → DOCX）。

---

## 核心功能

- **自动检索教学标准**：输入专业名称和层次，系统自动从内置数据源获取教学标准（无需手动上传）
- **双源整合**：融合教学标准与职业分析报告，生成课程体系、培养规格、职业面向等核心章节
- **合规校验**：自动校验学时学分比例（中职 ≥3000学时、公共基础课 ≥33%、实践 ≥50%）
- **文档交付**：输出标准格式的 Markdown 和 Word（DOCX）文档，含课程体系架构图
- **交互确认**：课程体系生成后支持用户审核调整（最多3轮）

## 快速开始

### 输入材料

| 材料 | 必需 | 说明 |
|------|:----:|:-----|
| **专业名称 + 教育层次** | ✅ | 如"西餐烹饪（740202）中职"、"数字媒体技术（510204）中高职一体化" |
| **职业分析报告** | ✅ | 该专业的岗位调研/职业分析报告（PDF/DOCX/TXT） |
| **专业教学标准** | ⬜ | 可自动检索获取，也可手动上传文件（PDF/DOCX） |

> 💡 系统内置 1443 条专业目录、579 条教学标准 PDF 索引、274 个专业简介文件，覆盖大部分职业教育专业。

### 输出文件

```
output/<专业名称>专业/
├── <专业>人才培养方案.md          ← Markdown 源文件
├── <专业>人才培养方案.docx        ← 最终交付文件
└── images/
    └── 课程体系架构图.png         ← 嵌入 DOCX
```

## 使用流程

### 方式一：自动检索（推荐）

仅提供专业名称和教育层次，系统自动获取教学标准：

```
Phase 0.5: 自动检索专业教学标准
Phase 0:   预处理输入文档
Phase 1-3: 提取教学标准 + 职业分析报告数据
Phase 4:   融合数据并生成课程体系
Phase 5:   Markdown → DOCX 转换
```

### 方式二：手动上传

若需要特定版本的教学标准，可手动上传 PDF/DOCX 文件，系统跳过自动检索直接进入预处理。

## 技术架构

### 数据源检索流程

```
用户输入（专业名称 + 层次）
        ↓
Step 1: 从 XLSX 检索 → 专业代码 + 专业类代码
        ↓
Step 2: 用专业代码查 JSON → PDF URL
        ↓
Step 3: JSON 无结果 → 用类代码查 MD 目录 → 专业简介
        ↓
Step 4: 均未找到 → 提示用户上传
```

### 生成流程（6 Phase）

| Phase | 内容 | 关键操作 |
|:-----:|:-----|:---------|
| **0.5** | 自动检索 | 专业目录 → PDF URL → 专业简介 |
| **0**   | 预处理    | PDF/DOCX → Markdown（保留表格） |
| **1-3** | 数据提取  | 教学标准课程 + 职业报告学习领域 |
| **4**   | 融合生成  | 双源映射、合并课程、学时分配 |
| **5**   | 输出交付  | 架构图生成 → pandoc → DOCX 后处理 |

### 关键规则

| 规则 | 内容 |
|------|------|
| **规则A** | 课程体系架构图必须嵌入 MD，PNG 保存到 `images/` 子目录 |
| **规则B** | 表4 公共基础课必须从模板提取国家标准内容，仅允许专业名称替换 |
| **规则C** | 其余章节基于教学标准+职业分析报告融合生成 |
| **规则D** | 专业课程目标必须从双源材料提取整合，禁止 LLM 纯推理生成 |

### 学时底线

| 层次 | 总学时 | 公共基础课 | 选修课 | 实践 |
|------|--------|-----------|--------|------|
| 中职（三年制） | ≥3000 | ≥33% | ≥10% | ≥50% |
| 高职（三年制） | ≥2500 | ≥25% | ≥10% | ≥50% |
| 一体化（五年制） | ≥4500 | ≥25% | ≥10% | ≥50% |

## 自检验收

生成完成后自动执行 40 项自检，包括：

- [x] 章节完整性、表格列数一致性
- [x] 无残留占位符或 "XX" 文本
- [x] 学时学分计算正确
- [x] 课程体系架构图已嵌入 DOCX
- [x] 表4 公共基础课复用模板原文
- [x] 所有能力条目采用 "能力+行动" 结构
- [x] 表3 职业能力列无代码编号
- [x] 表格边框已添加、表头加粗居中
