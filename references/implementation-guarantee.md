# 实施保障生成规则（第8章）

> 本文件为 Phase 4"实施保障"章节生成的详细规则，在生成第8章时**必须加载**。
>
> **数据来源**：师资队伍/教学设施/教学资源/质量保障的量化指标**必须从教学标准第9（师资队伍）/10（教学条件）/11（质量保障和毕业要求）部分提取**，禁止 LLM 猜测数字。

## 生成策略：模板基准 + 教学标准覆盖

1. **默认基准**：采用对应层次模板第8章内容（`assets/人才培养方案-中职模板.md` 或 `assets/人才培养方案-高职模板.md`）
2. **标准覆盖**：若教学标准含第9/10/11部分，提取量化指标**覆盖**模板对应数值
3. **兜底**：教学标准未提供第9/10部分时，采用下方国标底线表数值

## 量化指标对照表（中职 vs 高职）

| 指标 | 中职国标值 | 高职国标值 | 标准条款 |
|------|-----------|-----------|---------|
| 专任教师与学生比 | ≤ 20:1 | ≤ 25:1 | 9.1 |
| 高级职称专任教师占比 | ≥ 20% | ≥ 20% | 9.1 |
| 双师型占专业课教师 | ≥ 50% | ≥ 60% | 9.1 |
| 专任教师企业实践 | 每年≥1个月，5年累计≥6个月 | 同左 | 9.3 |
| 兼职教师 | 中级职称或高级工及以上 | 同左 | 9.4 |

> **注意**：师生比/双师比例中职与高职不同（20:1 vs 25:1；50% vs 60%），生成时必须按教育层次选用对应值。

## 字段提取规则

### （一）师资队伍

| 字段 | 提取来源 | 规则 |
|------|:--------|:-----|
| 师生比/职称/双师比例 | 教学标准9.1 | 采用标准数值，覆盖模板基准 |
| 专业带头人 | 教学标准9.2 | 副高及以上职称+实践能力+行业联系+主持专业建设 |
| 专任教师 | 教学标准9.3 | 教师资格+学历+课程思政落实+企业实践年限 |
| 兼职教师 | 教学标准9.4 | 中级职称或高级工及以上+能承担教学/实习指导 |

**示例输出（中职）**：
> 专任教师与学生比例不高于1:20，专任教师中高级职称占比不低于20%，双师型教师占专业课教师比例不低于50%。专任教师每年至少1个月在企业或生产性实训基地锻炼，每5年累计不少于6个月的企业实践经历。

**示例输出（高职）**：
> 专任教师与学生比例不高于1:25，高级职称专任教师占比不低于20%，双师型教师占专业课教师比例不低于60%。

### （二）教学设施

| 字段 | 提取来源 | 规则 |
|------|:--------|:-----|
| 专业教室 | 教学标准10.1.1 | 直接采用（信息化教学、安全设施要求） |
| 专业实训室 | 教学标准10.1.2 | **逐项提取**（设备清单+用途），替换模板通用实训室清单 |
| 实习基地 | 教学标准10.1.3 | 三方协议+岗位覆盖+双指导教师要求 |

**规则**：实训室清单以教学标准10.1.2为准（如"服装设计实训室""石油仪表实训室"为专业特有），模板清单仅作基准框架，两者冲突时以教学标准为准。

### （三）教学资源

| 字段 | 提取来源 | 规则 |
|------|:--------|:-----|
| 教材 | 教学标准10.2.1 | 优先国家规划教材，体现新技术新规范 |
| 图书文献 | 教学标准10.2.2 | 按专业列举类型（政策法规/岗位标准/技术手册/实务案例） |
| 数字资源 | 教学标准10.2.3 | 教学资源库建设要求（音视频/课件/案例库/虚拟仿真软件） |

### （四）质量保障（对应模板第8章（六））

教学标准11.1 提取以下内容：
- **评价改革**：改进结果评价，强化过程评价，探索增值评价，吸纳行业组织、企业等参与评价，健全综合评价
- **教学管理**：巡课、听课、评教、评学制度，与企业联动的实践教学环节督导制度
- **教研活动**：线上线下结合的集中备课制度，定期教学研讨
- **毕业生跟踪**：毕业生跟踪反馈机制及社会评价机制，对生源情况、职业道德、技术技能水平、就业质量等进行分析，定期评价人才培养质量和培养目标达成情况

### （五）毕业要求（对应模板第9章）

教学标准11.2 提取以下内容：
- **毕业条件**：完成规定的实习实训，全部课程考核合格或修满学分，准予毕业
- **达成度**：严把毕业出口关，确保学生毕业时完成规定的学时学分和各教学环节，保证毕业要求的达成度
- **学分转化**：接受职业培训取得的职业技能等级证书、培训证书等学习成果，经学校认定可转化为相应的学历教育学分

## 边界规则

- 师资/设施量化指标**必须来自教学标准第9/10部分或本文件国标底线表**，禁止 LLM 猜测数字
- 实训室清单以教学标准10.1.2为主，模板清单作为基准框架，冲突时以教学标准为准
- 教学标准未提供第9/10/11部分时，使用本文件国标底线表兜底，并在方案中标注"（依据国家通用标准）"
- 中职/高职数值差异（20:1 vs 25:1、50% vs 60%）必须按教育层次正确选用
